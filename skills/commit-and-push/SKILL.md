# Git Commit Message Guidelines
- Imperative mood ("Add X", not "Added X")
- Subject ≤ 50 chars, body wrapped at 72
- Body explains *why*, not *what*
- Use Conventional Commits prefix when applicable: `feat:`, `fix:`, `refactor:`, `docs:`, `test:`, `chore:`
- Reference issues as `#123`

Example:
fix: prevent duplicate token issuance on rapid refresh

# After you wrote proper git commit message
- Commit (with the message you created) and push automatically.
